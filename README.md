# Telecom-Customer-Churn-Insights Dashboard by Manas Gupta

## Project Overview
This project analyzes customer churn data for **Databel Telecom**, a subscription-based telecom company[cite: 7].  
The goal is to **identify key churn drivers**, analyze customer behavior patterns, and present actionable insights through an interactive dashboard to help reduce customer attrition[cite: 7].

---

## Dataset Information
The dataset contains anonymized customer records, including:
- **Demographics:** Gender, Age, Senior Citizen status[cite: 7]
- **Subscription details:** Contract type, Plan type, Monthly charges, Tenure[cite: 7]
- **Usage behavior:** International calls, Internet usage, Support calls[cite: 7]
- **Target variable:** Churn (Yes/No)[cite: 7]

---

## Key Steps & Methodology

### 1. Data Preparation
- Cleaned and formatted raw Excel data for consistency[cite: 7].  
- Created calculated columns to derive key performance indicators (KPIs) such as **churn rate** and **average monthly charges**[cite: 7].  

### 2. Exploratory Analysis
- Conducted initial churn rate calculations across multiple categories[cite: 7].  
- Used **PivotTables** and calculated fields to explore patterns by demographics, plan type, contract length, and geographic distribution[cite: 7].  

### 3. Dashboard Creation
- Designed an **interactive Excel dashboard** summarizing[cite: 7]:
  - Churn KPIs and trends (Total Customers: 6,687 | Churn Rate: 26.86%)  
  - Customer demographics and age group breakdowns  
  - Usage and contract-based churn insights  

---

## Insights & Results
- Analyzed **7,000+ customer records** to reveal top root causes of customer migration[cite: 7].  
- Identified that **month-to-month contracts** suffer from high churn tendency, whereas long-term contracts heavily mitigate attrition.  
- Highlighted primary competitor factors (*"Competitor made better offer"* and *"Competitor had better devices"*) as top reasons for leaving, alongside support staff dissatisfaction.  
- Provided actionable recommendations to improve customer retention through targeted engagement strategies[cite: 7].
